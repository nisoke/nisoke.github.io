# Changxu's Blog

Personal blog of nisoke, built with [Hexo](https://hexo.io/) and the [NexT (Gemini)](https://theme-next.js.org/) theme, published to GitHub Pages.

## 本地预览

```bash
npm install
npx hexo server
```

然后在浏览器打开 http://localhost:4000 。

## 发布

推送到 `master` 分支即可，GitHub Actions 会自动构建并部署到 GitHub Pages（https://nisoke.github.io）。

## 写新文章

```bash
npx hexo new "文章标题"
```
